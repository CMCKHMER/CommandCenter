📖 Quick Reference Guide

✨ Prefixes

  • un- = not (happy → unhappy)
  • re- = again (write → rewrite)
  • pre- = before (view → preview)
  • dis- = opposite (agree → disagree)
  • mis- = wrongly (understand → misunderstand)

✨ Suffixes

  • -er/-or = one who (teach → teacher)
  • -ing = action (run → running)
  • -ly = manner (quick → quickly)
  • -ness = state (kind → kindness)
  • -able = capable (read → readable)
